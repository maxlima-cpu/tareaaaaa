# Guía de instalación de Python

## 1. Introducción

### 1.1 ¿Qué es Python?

Python es un lenguaje de programación de alto nivel, interpretado y de código abierto.

### 1.2 ¿Para qué se utiliza?

Python puede utilizarse en:

- Desarrollo web.
- Ciencia de datos.
- Inteligencia Artificial.
- Automatización de tareas.

## 2. Requisitos

Para instalar Python se requiere:

- Una computadora personal.
- Acceso a Internet.
- Sistema operativo compatible 

## 3. Proceso de instalación

### 3.1 Descargar Python

1. Ingresar al sitio web oficial de Python.
2. Seleccionar la versión correspondiente a su sistema operativo.
3. Descargar el instalador ejecutable.

[Visitar sitio oficial](https://www.python.org/)

[Consultar documentación](https://docs.python.org/3/)

### 3.2 Ejecutar la instalación

Ejecute el instalador descargado y siga los pasos indicados. Asegúrese de marcar la casilla **"Add python.exe to PATH"**.

![Logo de Python](https://www.python.org/static/img/python-logo.png)

### 3.3 Verificar la instalación

Abra una terminal y ejecute:

```bash
python --version
